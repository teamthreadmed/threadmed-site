# Thread Medicine OS: source

Builds `tools/thread-medicine-os.html`, a single static page.

    python3 build.py

## Files
- `nodes.py`: the node graph. One `n(id, title, kind, summary, b=rows, c=children, l=threads, w=widget)` call per node.
  - `b` rows are `(label, text)` or `(label, text, source_url)`.
  - `c` lists child node ids (drill-down). `l` lists `(node_id, why)` threads (cross-links).
- `modules.py`: the nine function modules with graded options. Each row is `(kind, text, grade, checked)`;
  `checked=True` draws a solid badge (verified against a primary source), otherwise dashed.
- `explorer.html`: page template, styles, calculators and the whole-web view.
- `control.svg`: the control-loop diagram.

## Adding a node
1. Add an `n(...)` call in `nodes.py`.
2. Add its id to a parent's `c` list.
3. Add threads with `l=[('other-id', 'why')]`.
4. Run `build.py`. It fails if a child or thread points at a node that does not exist, or if a node is unreachable.

## Conventions
- A status row says whether a node was checked against a primary source or is from working knowledge.
- Bump the version in the `explorer.html` header when publishing.
- The wheel poster (`assets/thread-medicine-os-wheel.png`) is a screenshot of the web view and is regenerated by hand.
